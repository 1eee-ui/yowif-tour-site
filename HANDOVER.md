# Передача сайта YoWif

Исполнитель: Настя (разработчица)
Заказчик: YoWif, организация GitHub `yowif-band` (Настя, заказчица)
Дата передачи: 25.09.2026

## Что передаётся

- Исходный код сайта и сервера (репозиторий `yowif-band/yowif-site`).
- Сайт: страницы Home, Band, Tour, Contact, Checkout, Privacy, 404.
- Сервер: оплата билетов через Stripe, письмо-билет через Resend, форма
  связи, подписка на новости, база PostgreSQL, проверка `/health`.
- Админ-панель `/admin`: заказы со статусами, сообщения, подписчики.
- 24 автотеста (`npm test`), которые GitHub Actions запускает при каждом
  изменении.

## Секреты

Пароли и ключи **не хранятся в коде**. Они задаются в настройках хостинга
(переменные окружения) или локально в файле `.env`, который не попадает
на GitHub.

| Переменная | Что это | Кто задаёт |
|---|---|---|
| `ADMIN_PASSWORD` | Пароль админ-панели, не короче 10 символов | Заказчик |
| `PORT` | Порт сервера, хостинг задаёт сам | — |
| `DATABASE_URL` | Строка подключения к базе PostgreSQL (Supabase) с паролем базы. Без неё данные хранятся в файлах и стираются при перезапуске | Заказчик |
| `STRIPE_SECRET_KEY` | Секретный ключ Stripe. `sk_test_...` — тестовые платежи, `sk_live_...` — настоящие деньги. Без ключа оплата в демо-режиме | Заказчик. Боевой ключ — только заказчик, после исключения исполнителя |
| `STRIPE_WEBHOOK_SECRET` | Секрет вебхука Stripe (`whsec_...`): подтверждает, что сообщение об оплате пришло от Stripe | Заказчик |
| `RESEND_API_KEY` | Ключ сервиса писем Resend. Без него письма с билетами не отправляются | Заказчик |
| `MAIL_FROM` | Адрес отправителя писем, например `YoWif <tickets@ваш-домен>`. Нужен свой домен, подтверждённый в Resend | Заказчик, когда появится домен |

Все значения заказчик задавал сам в своих аккаунтах. Исполнитель их не знает.

## Как обновлять сайт

1. Изменить файлы в репозитории на GitHub (или локально и отправить через `git push`).
2. GitHub Actions проверит изменения тестами (зелёная галочка у коммита).
3. Render сам пересоберёт и перезапустит сайт. Если новая версия сломалась,
   в Render → Deploys можно откатиться на предыдущую кнопкой Rollback.

## Ограничения

- Оплата через Stripe Checkout: карту покупатель вводит на странице Stripe,
  номера карт не попадают на сервер, в базу и в логи. Для реальных продаж
  заказчик активирует аккаунт Stripe (данные компании и счёт), создаёт
  боевой вебхук и заменяет тестовые ключи на боевые.
- Пока в Resend не подтверждён свой домен, письма с билетами приходят только
  на почту владельца аккаунта Resend, а не любому покупателю.
- Данные хранятся в PostgreSQL (Supabase), если задан `DATABASE_URL`.
  Без него сервер пишет в JSON-файлы в папке `data`, это режим для
  разработки.
- Бесплатный Supabase приостанавливает проект после недели без активности,
  а бесплатный Render засыпает после 15 минут без посетителей. Чтобы этого
  не было, мониторинг (UptimeRobot) раз в 5 минут открывает `/health`:
  этот адрес проверяет сервер и делает запрос к базе. Если сайт или база
  не отвечают, UptimeRobot присылает письмо.

- `public/privacy.html`: вписать реальные реквизиты и email вместо

  политики — шаблон, его должен проверить юрист.
- `public/contact.html`: заменить демо-адреса `booking@` и `press@yowif.example`.
- При переходе на свой домен заменить адрес `yowif-site.onrender.com`
  в тегах `og:url` и `og:image` на страницах сайта (превью ссылок).
